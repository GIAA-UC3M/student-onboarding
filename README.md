# Bienvenido/a

Este repo contiene la guía de inicio para estudiantes que usan la plataforma de gestión de prácticas.

---

## Primeros pasos

### 1. Crea una cuenta en GitHub

Ve a [github.com](https://github.com) y crea una cuenta si no tienes una. Puedes usar tu email de estudiante para crearla. Si prefieres hacerlo con un mail personal, vincula tu cuenta de email de estudiante a tu cuenta de GitHub.

Guarda tu `@username` — lo necesitarás en el paso siguiente.

### 2. Dáselo a tu profesor

Comparte tu `@username` de GitHub con tu profesor por el canal que indique (correo, formulario, etc.).

El profesor te añadirá a la organización y te enviará una invitación. **Hasta que esto ocurra no puedes continuar.**

### 3. Acepta la invitación

Recibirás un correo de GitHub con el asunto *"You've been invited to join..."*. También puedes verla en [github.com/notifications](https://github.com/notifications).

### 4. Encuentra tu repositorio privado

Una vez aceptada la invitación, tu repositorio personal estará disponible en:

```
https://github.com/GIAA/{student-id}
```

Solo tú y el profesorado tenéis acceso.

### 5. Configura tu entorno y empieza

- [Instalar y configurar git →](git.md)
- [Conectar tu máquina con GitHub →](github.md)
- [Cómo recibir y entregar ejercicios →](student-workflow.md)

## Tus repositorios

### Tu repo privado — `GIAA/{student-id}`

Es tuyo: solo tú y el profesorado tenéis acceso. Contiene todo tu trabajo en la plataforma:

| Qué | Dónde |
|---|---|
| Ejercicios asignados | Pestaña **Issues** — una issue por ejercicio, con enunciado y fecha límite |
| Tus entregas | Pestaña **Pull requests** — una draft PR por ejercicio; la conviertes a Ready cuando entregas |
| Fechas de entrega | **Milestones** — uno por ejercicio con la fecha límite |
| Tus notas y feedback | **Issues** — busca `correction-review` con el nombre del ejercicio |
| Tu código | Ramas `ex/{subject-id}/{course}/exNN` — una por ejercicio |

### Repo compartido de la asignatura — `GIAA/{subject-id}-public`

Todos los estudiantes de la asignatura tenéis acceso de lectura. El profesorado publica aquí recursos como soluciones, material de apoyo o ejemplos.

No puedes hacer push directamente — el contenido lo gestiona el profesorado.
